# Chapter 9 — Data-Driven Auxiliary Function Methods

This directory contains the MATLAB scripts accompanying Chapter 9 of

> **Polynomial Optimization Methods for Dynamical Systems: Auxiliary Functions, Sum-of-Squares Programming, and Applications**  
> Jason Bramburger

The examples illustrate how auxiliary-function methods can be combined with data-driven operator approximation, moment constraints, weighted averages, reduced-order modeling, and feedback control.

## Requirements

Most scripts require

- MATLAB

Some scripts additionally require

- YALMIP
- MOSEK
- Chebfun

Specific requirements are listed in the headers of each script.

## Scripts

| Script | Description |
|---|---|
| `shear_flow_edmd_bounds.m` | Computes EDMD-based auxiliary-function bounds for a projected shear-flow model over a range of Reynolds numbers. |
| `shear_flow_edmd_bounds_plots.m` | Loads the saved EDMD bound data and reproduces the transition-detection figure. |
| `rossler_poincare_periodic_orbits.m` | Uses data-driven moment constraints for a Rössler Poincaré map to identify unstable periodic orbits. |
| `vdp_generator_convergence.m` | Demonstrates pointwise convergence of learned generator approximations for the Van der Pol oscillator. |
| `driven_logistic_weighted_birkhoff.m` | Compares ordinary and weighted Birkhoff averages for periodic, quasiperiodic, and chaotic responses of a driven logistic map. |
| `cylinder_generate_pod_data.m` | Simulates cylinder wake data, computes POD modes, and saves projected POD coefficients. |
| `cylinder_bounded_roms.m` | Learns unconstrained and bounded quadratic ROMs from the cylinder wake POD coefficients. |
| `rossler_ogy_control.m` | Implements data-driven OGY control for fixed-point and period-two stabilization in the Rössler Poincaré map. |

## Data files

Some scripts require auxiliary data files generated by other scripts or included with the repository.

| File | Used by | Description |
|---|---|---|
| `ShearICs.mat` | `shear_flow_edmd_bounds.m` | Initial conditions for the shear-flow EDMD example. |
| `random_projection_matrix.mat` | `shear_flow_edmd_bounds.m` | Random projection matrix used to define the low-dimensional shear-flow coordinates. |
| `cylinder_Re100_POD10_projected_all.mat` | `cylinder_bounded_roms.m` | POD coefficient data generated by `cylinder_generate_pod_data.m`. |

## Notes

Some examples are computationally intensive. In particular, the cylinder wake simulation and higher-degree EDMD-SOS shear-flow bounds may require substantial runtime and memory. The plotting scripts assume that the corresponding data files have already been generated.

## Output

Depending on the script, running an example produces

- printed numerical diagnostics,
- PDF figures,
- MAT files containing computed bounds, POD data, or learned models, and
- MP4 movies where appropriate.

All output files are written to the current working directory.
